# PharmaIQ System Design

PharmaIQ is designed as a modular AI decision intelligence platform.

- Frontend: React + TypeScript + TailwindCSS
- Backend: FastAPI with modular routes and AI assistant services
- ML: scikit-learn, XGBoost, SHAP, MLflow
- Data: streaming and document intelligence pipelines

Components:
- `backend/app/ai_assistant`: RAG and chat endpoints
- `ml_engine`: model training, explainability, and MLOps
- `streaming`: event producer/consumer stubs
- `recommendation_engine`: decision science recommendation skeleton
